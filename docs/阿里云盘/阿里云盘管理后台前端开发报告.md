## 实现内容

1. 授权接口封装
   - `getAdriveAuthorizeUrl`
   - `getAdriveTokenInfo`
   - `refreshAdriveToken`

2. 用户与空间接口封装
   - `getAdriveUserInfo`
   - `getAdriveDriveInfo`
   - `getAdriveSpaceInfo`
   - `getAdriveScopes`

3. 文件调试接口封装
   - `listAdriveFiles`
   - `createAdriveFile`

4. 管理页面
   - 展示授权状态、系统用户、阿里云盘用户、当前 Drive、过期时间和最近刷新时间。
   - 点击“授权阿里云盘”时调用后端授权地址接口，不在前端拼接 OAuth URL。
   - 打开授权页后不做自动轮询，授权完成后由用户点击“刷新状态”手动查询授权结果。
   - `status=enabled` 后并行加载用户信息、Drive 信息、空间信息和 Scope 信息。
   - 校验必需 Scope：`user:base`、`file:all:read`、`file:all:write`。
   - 提供“读取根目录”和“创建根目录”调试按钮，用于验证文件读写权限。

5. 权限控制
   - 授权、刷新状态、刷新 Token：`adrive:auth:manage`
   - 用户、Drive、空间、Scope 信息：`adrive:user:read`
   - 读取根目录：`adrive:file:read`
   - 创建根目录：`adrive:file:write`
