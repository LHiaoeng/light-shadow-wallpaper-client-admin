# 臻彩展示站 JSON 导出简化设计

> 状态说明（2026-07-14）：浏览器“导出到指定文件夹”已改为“写入指定文件夹”。前端填写服务器目录，
> 后端在允许的 data 根目录内追加 `prestige-chromas.json`；普通 JSON 下载继续保留。

## 目标

将管理前端“展示站数据”操作简化为两个明确动作，不再从前端触发服务器默认目录写入。

## 交互

保留“展示站数据”下拉按钮，菜单仅包含：

推荐目录显示在菜单顶部：
`D:\WebstormProjects\lol-prestige-chroma-hub\data\`。
该路径只用于提示用户选择目标文件夹；受浏览器安全限制，页面不会自动打开、定位或写入该路径。

1. `导出 JSON 文件`：调用现有 JSON 下载接口，使用浏览器普通下载。
2. `导出到指定文件夹`：先选择本地文件夹，再调用同一下载接口，将文件直接写为
   `prestige-chromas.json`。

两项都只使用 `lol:prestige:hub-download` 权限。移除前端的 `hub-write` 权限判断、服务器默认目录写入、
写入确认弹窗及相关 API 调用。

## 异常处理

- 用户取消文件夹选择时静默结束。
- 浏览器不支持文件夹选择时提示使用普通下载，不自动下载。
- 下载或文件写入失败继续交给现有全局错误处理，不伪造成功提示。

## 验证

- 触及文件 ESLint 通过。
- Vue/TypeScript 类型检查通过。
- 前端源码不再引用 `lol:prestige:hub-write` 或服务器写入 API。
- 下拉菜单显示完整推荐目录，两个导出动作的行为保持不变。
